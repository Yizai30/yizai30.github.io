- I = Integer（整数）

# 点到点距离约束
```cpp
double ConstraintP2PDistance::error() { 
    double dx = (*p1x() - *p2x()); 
    double dy = (*p1y() - *p2y()); 
    double d = sqrt(dx*dx + dy*dy); // 当前距离 
    double dist = *distance(); // 目标距离
    return scale * (d - dist); // 距离误差
}
```

这段代码实现了一个几何约束类 ConstraintPointOnLine 中的 error() 函数。它的主要目的是计算当前距离和目标距离的误差，并乘以一个缩放因子 scale。

下面是逐行解释：

```cpp
double ConstraintPointOnLine::error() {
```
含义：这是类 ConstraintPointOnLine 的成员函数 error 的定义，返回类型为 double。
作用：在优化问题（如Bundle Adjustment或SLAM）中，error() 通常用于计算当前状态下的残差（即误差值）。这里具体指点到直线约束的几何误差。

dx 就是 Δx，dy 就是 Δy，计算当前的两点间距离为 d，存储目标距离为 dist，用 scale 进行权重缩放。

# 点在线上约束
```cpp
double ConstraintPointOnLine::error() { // 使用叉积计算点到线的有向距离 
double area = -x0*dy + y0*dx + x1*y2 - x2*y1; double d = sqrt(dx*dx + dy*dy); return scale * area / d; // 点到线的距离 
}
```
计算面积，计算底，用面积和底求高，即是距离。

# 相等约束

```cpp
double ConstraintEqual::error() { return scale * (*param1() - ratio * (*param2())); }
```

这段代码实现了一个相等约束（Equality Constraint）的误差计算函数。它的核心逻辑是计算两个参数值之间的加权差值，但其中一个参数在比较前被乘以了一个比例系数 ratio。

这通常用于优化问题（如 Bundle Adjustment、SLAM 或曲线拟合），目的是让 param1 的值尽可能接近 param2 的 ratio 倍。

总结与数学公式

这段代码实现的数学逻辑是：

$ \text{Error} = w \cdot (x_1 - k \cdot x_2) $

其中：
$ x_1 = \text{*param1()} $ （第一个参数的值）
$ x_2 = \text{*param2()} $（第二个参数的值）
$ k = \text{ratio} $（比例系数）
$ w = \text{scale} $（权重/缩放因子）

应用场景举例：
假设你在做一个机器人定位：
param1 是传感器测得的距离（单位：米）。
param2 是地图上的像素距离（单位：像素）。
ratio 是地图的比例尺（例如 0.05 米/像素）。
这个约束的作用就是强制：“传感器测得的米数”应该等于“像素数”乘以“比例尺”。如果不相等，error() 就会返回一个非零值，驱动优化算法去调整参数直到等式成立。
